📖 Muallim ul-Qur'an PWA (v2.0.0)

An interactive, offline-first Progressive Web App for learning Qur'anic Arabic vocabulary via Hinglish (Hindi written in Roman script). 7 Units, 114 lessons, lazy loading, and teacher administration.

Live PWA Application: https://nomaanc.github.io/muallim/

Dedicated Admin Dashboard: https://nomaanc.github.io/muallim/admin.html

GitHub Repository: github.com/nomaanc/muallim

Architecture (v2.0.0 Modular Split)

Modern Modular Production Architecture

In Version 2.0.0, the monolithic 4.2 MB index.html was refactored into a high-performance modular system:

  • index.html (404 lines): A lean shell containing HTML layout, 10 native <dialog> modals, and the native HTML popover hamburger menu. Zero inline book data.
  • css/styles.css (978 KB): Clean standalone stylesheet for themes, typography, and responsive layouts.
  • js/app.js (135 KB): Modular JavaScript application encapsulated in an IIFE and exported to window.App.
  • data/metadata.json (10 KB): Lightweight index loaded on boot.
  • data/unit1.json – unit7.json: Split unit datasets loaded on demand.
  • admin.html (1,534 lines): Standalone dashboard served at /admin.html.
✅ No build step required: Runs as pure vanilla web standards directly on GitHub Pages with zero npm or bundler dependencies.

Developer Guide

Setup & Running

  1. Clone the repository: git clone https://github.com/nomaanc/muallim.git
  2. Working directory: pwa/
  3. Open index.html in any modern browser.
  4. Verify JavaScript syntax anytime: 
    node --check js/app.js

Git Workflow

# 1. Edit code
# 2. Check syntax:
node --check js/app.js

# 3. Stage, commit, and push:
git add -A
git commit -m "feat: description of changes"
git push origin main

# GitHub Pages automatically publishes updates within seconds!

Critical Invariants

🚫 NEVER translate "Exercise" to "Mashq" — it remains "Exercise" everywhere in Hinglish.
🚫 NEVER strip, alter, or normalize Arabic harakat (diacritics). Preserve all 100,115 vowels intact.
⚠️ Always display "Unit" in UI labels (internal schema retains stage_id).
ℹ️ Hinglish text strictly adheres to Subject-Object-Verb (SOV) order matching spoken Urdu.

Admin Dashboard (`admin.html`)

Served at https://nomaanc.github.io/muallim/admin.html as a dedicated, secure administration environment:

  • Auth Guard: Checks onAuthStateChanged and verifies /users/{uid}.role === 'admin'. Unauthorized users are immediately redirected.
  • Overview: Displays metrics cards (Total Users, Active Students, Exam Results, Broadcasts) and live recent activity feed.
  • Students Table: Sortable by Name, Last Active, Stars Count, Exam Count. Clicking a row expands detailed exam history and last bookmark.
  • Exam Manager: Create new "Ustaad ki Exam" by selecting units and lesson numbers; delete expired exams.
  • Broadcasts: Live message broadcaster with character limit counter and past broadcasts audit log.
  • User Management: Toggle user roles between Student and Admin; delete user records.
  • Responsive Design: Sidebar navigation on desktop, sticky tab bar on mobile.

Study Session Time Tracking

Integrated directly in js/app.js via flushSessionTime():

  1. When a student navigates to a lesson, _sessionStart records the timestamp and _sessionLessonKey.
  2. Upon navigating to another lesson or closing the tab (beforeunload), elapsed time is calculated.
  3. If elapsed time > 10 seconds and user is logged in, Firestore increments the lesson's total study seconds via firebase.firestore.FieldValue.increment(elapsed) in /user_data/{uid}.lessonTime.{lessonKey}.
  4. Accumulated time is also stored locally in localStorage['muallim_lesson_time'].
